# ⚠️ DATASET NOTICE

## The Ge'ez Character Dataset Used in This Research is NOT Publicly Available

**🔒 No dataset access requests will be entertained.**

### Reasons for Restriction

1. **Institutional Agreements:** The dataset was collected under strict access agreements with Ethiopian Manuscript Microfilm Library (EMML), Institute of Ethiopian Studies (IES), Tigray Monasteries, and Axum Heritage Sites that prohibit redistribution.

2. **Cultural Heritage Protection:** The manuscripts are culturally and historically significant artifacts requiring controlled access.

3. **Privacy and Sensitivity:** Some manuscript sources contain sensitive religious and cultural content.

### What is Provided Instead

- **Synthetic Data Generator:** `data/sample_data.py` creates test images for verifying the model
- **Complete Model Code:** All architecture and training code is provided
- **Preprocessing Pipeline:** Full preprocessing scripts are included
